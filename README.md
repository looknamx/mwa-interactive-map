# แผนที่โรงงานผลิตน้ำแบบ Interactive

เว็บไซต์แผนที่สำหรับหน่วยงานการประปานครหลวง ออกแบบให้ฝังในเว็บไซต์เดิมด้วย iframe พร้อมหน้าจัดการ Label สำหรับผู้ดูแลระบบ

## ไฟล์สำคัญ

- `index.html` — หน้าตัวอย่างการฝัง iframe และตัวอย่างโค้ด
- `map.html` — หน้าแผนที่จริงสำหรับใช้เป็น `src` ของ iframe
- `admin.html` / `admin.css` / `admin.js` — หน้าจัดการ Label
- `map.css` — รูปแบบหน้าจอ สี Label และ Responsive layout
- `map.js` — การสร้างแผนที่ การค้นหา ตัวกรอง Popup และโหมดพิกัด
- `leaflet-fallback.css` — CSS สำรองสำหรับตำแหน่ง pane และ Label หาก CDN stylesheet ถูกบล็อก
- `map-data.js` — ข้อมูล Label และประเภทพื้นที่ทั้งหมด
- `images/plant-map.jpg` — ภาพพื้นหลังแผนที่ ขนาด 992 × 813 พิกเซล

## การเปิดใช้งานด้วย Live Server

1. เปิดโฟลเดอร์นี้ใน Visual Studio Code
2. ติดตั้ง Extension ชื่อ **Live Server** โดย Ritwick Dey (หากยังไม่มี)
3. คลิกขวาที่ `index.html` แล้วเลือก **Open with Live Server**
4. เบราว์เซอร์จะเปิดที่ URL ลักษณะ `http://127.0.0.1:5500/index.html`

เปิด `admin.html` เพื่อจัดการข้อมูล Label การแก้ไขในรุ่นทดลองจะเก็บใน `localStorage` ของเบราว์เซอร์เครื่องนั้น และหน้า iframe ที่เปิดจากโดเมนเดียวกันจะอ่านข้อมูลชุดเดียวกัน

## การฝังในเว็บไซต์เดิม

```html
<iframe
  src="/interactive-map/map.html"
  title="แผนที่โรงงานผลิตน้ำ"
  width="100%"
  height="760"
  style="border: 0"
  loading="lazy">
</iframe>
```

ควรวางโฟลเดอร์แผนที่ทั้งหมดไว้ภายใต้เว็บไซต์เดิมและให้ `map.html` กับ `admin.html` อยู่ในโดเมนเดียวกัน เพื่อให้ข้อมูลทดลองจาก Admin ถูกอ่านผ่าน iframe ได้

ระบบ Admin รุ่นทดลองใช้ PIN `2468` และจดจำสิทธิ์เฉพาะแท็บปัจจุบัน สามารถเปลี่ยน PIN ได้ที่ตัวแปร `ADMIN_PIN` ใน `admin-auth.js`

> PIN ที่เขียนอยู่ใน JavaScript ป้องกันได้เพียงการเข้าถึงทั่วไป ผู้ที่ตรวจ source code ยังสามารถเห็น PIN ได้ ก่อนใช้งานจริงควรตรวจ PIN ที่ API ฝั่งเซิร์ฟเวอร์ และเก็บรหัสแบบ hash พร้อมจำกัดจำนวนครั้งที่ลอง

หน้า Admin รองรับการเพิ่ม แก้ไข ลบ คืนค่าเริ่มต้น นำเข้า JSON และส่งออก JSON เมื่อต้องการกำหนดตำแหน่ง ให้คลิกบนภาพตัวอย่าง ระบบจะกรอกค่า `x` และ `y` ให้อัตโนมัติ

ไม่แนะนำให้เปิดด้วยการดับเบิลคลิกไฟล์โดยตรง (`file://`) เพราะเบราว์เซอร์บางตัวจำกัดการทำงานของ Clipboard และการโหลดทรัพยากร

Leaflet เวอร์ชันทดลองโหลดผ่าน CDN จึงต้องเชื่อมต่ออินเทอร์เน็ต เมื่อจะใช้งานภายในองค์กร สามารถดาวน์โหลด `leaflet.css`, `leaflet.js` และโฟลเดอร์รูปไอคอนมาเก็บในเซิร์ฟเวอร์ แล้วแก้ `href` และ `src` ใน `index.html` ให้ชี้ไปยังไฟล์ดังกล่าวได้โดยไม่ต้องแก้โค้ดแผนที่

## การเพิ่ม Label ใหม่

1. เปิดโหมด **กำหนดตำแหน่ง Label** ที่แถบเครื่องมือ
2. คลิกตำแหน่งบนภาพ แล้วกด **คัดลอกพิกัด**
3. เปิด `map-data.js` และเพิ่ม object ใหม่ใน array `window.MAP_LABELS`

ตัวอย่าง:

```js
{
  id: "chemical-building",
  label: "CHEMICAL BUILDING",
  name: "อาคารสารเคมี",
  x: 45.25,
  y: 31.80,
  category: "support",
  description: "อาคารจัดเก็บและจ่ายสารเคมีสำหรับกระบวนการผลิตน้ำ",
  downloads: [
    {
      label: "ข้อมูลอาคารสารเคมี (PDF)",
      url: "documents/chemical-building.pdf",
      sample: false
    }
  ]
}
```

ค่า `x` วัดจากซ้ายไปขวา และ `y` วัดจากบนลงล่าง โดยใช้หน่วยเปอร์เซ็นต์ ควรกำหนด `id` ไม่ซ้ำกัน

ประเภท (`category`) ที่รองรับ:

| ค่า | ประเภท | สี |
|---|---|---|
| `production` | ระบบผลิตน้ำ | น้ำเงิน |
| `transmission` | ระบบส่งน้ำ | ฟ้า Cyan |
| `civil` | งานโยธา | ส้ม |
| `support` | อาคารสนับสนุน | เขียว |

หากต้องการใช้ไฟล์ดาวน์โหลดจริง ให้วางไฟล์ในโฟลเดอร์ `documents` ปรับ `url` ให้ตรงชื่อไฟล์ และตั้ง `sample: false` ระหว่างที่ยังไม่มีไฟล์จริงให้ใช้ `sample: true` เพื่อแสดงป้ายและข้อความว่าเป็นไฟล์ตัวอย่าง

## การเปลี่ยนภาพแผนที่

เมื่อเปลี่ยนภาพ ต้องแก้ `imageUrl`, `imageWidth` และ `imageHeight` ใน `window.MAP_CONFIG` ให้ตรงกับไฟล์ใหม่ แผนที่จะรักษาสัดส่วนภาพตามค่าดังกล่าวและไม่ยืดหรือบิดเบี้ยว จากนั้นควรตรวจตำแหน่ง Label ด้วยโหมดกำหนดพิกัดอีกครั้ง
